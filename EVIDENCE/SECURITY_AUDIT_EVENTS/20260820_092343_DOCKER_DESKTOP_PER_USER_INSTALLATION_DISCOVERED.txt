SUMMARY
-------

Docker Desktop is installed per-user under LocalAppData Programs and exposes the docker desktop CLI subcommand.


EVIDENCE
--------

Docker Desktop version 4.86.0 was found in the Windows uninstall registry. docker.exe resides under the per-user DockerDesktop installation. Start Menu registration exists and docker desktop --help succeeds.


SECURITY IMPACT
---------------

The previous launcher failure was caused by incorrect assumed installation paths, not by a missing Docker Desktop installation.


REMEDIATION
-----------

Use docker desktop start instead of hard-coded executable paths, then validate the Docker engine three times.
