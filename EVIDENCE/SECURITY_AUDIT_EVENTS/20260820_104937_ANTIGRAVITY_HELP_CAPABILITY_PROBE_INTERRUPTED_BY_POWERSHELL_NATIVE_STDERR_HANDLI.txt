Title:
Antigravity help capability probe interrupted by PowerShell native stderr handling

Component:
Security audit tooling

Category:
PowerShell native command handling

Status:
TEST


SUMMARY
-------

The Antigravity CLI help probe was interrupted before capability analysis because Windows PowerShell promoted native stderr output to NativeCommandError while ErrorActionPreference was Stop.


EVIDENCE
--------

The probe stopped immediately after the CLI emitted its Usage text, so no reliable conclusion about supported flags was produced.


SECURITY IMPACT
---------------

Antigravity CLI capability flags remain unverified.


REMEDIATION
-----------

Capture native stdout and stderr under ErrorActionPreference Continue, preserve LASTEXITCODE immediately, and analyze the resulting help text afterward.
